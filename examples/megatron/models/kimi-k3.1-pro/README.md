# Kimi K3.1 Pro on MI455X

The 4-layer Kimi K3.1 Pro proxy runs on one node of 4x MI455X with
`examples/megatron/configs/MI455X/kimi_k3.1_pro_4L-BF16-pretrain.yaml`.

For the image, the launcher and how to run it, see
[`examples/megatron/guides/mi455x_package`](../../guides/mi455x_package/).
`hipblaslt_tuning/` holds the hipBLASLt table the recipe loads.
